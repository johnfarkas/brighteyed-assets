Assets

Pattern

One shape, six jobs — the mark itself among them. Every device is built from the same spark at the same proportions, so the system stays legible when it is used a lot and quiet when it is used a little.

The fields

Two tiling patterns, both seamless. Set them as a repeating fill at any scale — the pitch is stated in multiples of S, so pick S for the surface and the pattern follows. Tints are baked into the files as flat colors, ready for a printer.

The divisions

Two devices that do not tile. Each one takes a whole surface.

The point

The sixth use, at text size. Set to the cap height of the type beside it, the spark separates menu sections, marks a list, or ends a paragraph. Each menu section keeps its own color, so the point carries the section as well as the break.

Using them

One device per surface

A field or a division or a crop, and the mark. Two patterns on one piece read as noise, and the geometry stops being the point.

Rotations only

The tile turns 0°, 90°, 180°, 270°. A reflection breaks the checker and puts two same-value quadrants side by side.

The mark reconciles inside

Where the lockup sits on a lattice, it occupies one cell of the same grid, so the mark is the cell where the field takes color. The tile stays full strength; the field stays a tint.

Anything past the six

Is decoration. The spark is a precise object with one governing dimension, and the six devices are the whole vocabulary.
